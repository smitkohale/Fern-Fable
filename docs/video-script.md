# Walkthrough video: 75 seconds

Goal: show a hiring manager, fast, that you can build a real Shopify theme (Liquid, sections, the Cart API, accessibility) and not just a pretty homepage. Record **after** importing the products and adding photos.

**Set up before recording**
- Products imported, menus set, a few photos in. Festive mode on (it is Christmas season).
- Chrome at 1440 x 900, zoom 100%, bookmarks bar hidden, one tab.
- Cart empty. Log into the store so the preview has no password page.
- Record with **Win + Alt + R** (Xbox Game Bar) or OBS at 1080p. Narrate live or add a voice over afterwards; captions on screen either way.
- Move the mouse slowly. Pause half a second on anything you want remembered.
